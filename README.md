# 마피아 온라인 (6~20명 웹앱)

참가자가 계정 없이 **방 코드나 QR만으로** 폰에서 들어오는 마피아 게임입니다.
사회자 1명이 노트북에서 방을 만들고, 참가자 **최대 20명**이 각자 폰으로 직업 확인, 밤 행동, 낮 투표를 합니다.

- **화면(사이트)**: Vercel 또는 Firebase Hosting에 올립니다. 둘 다 무료입니다.
- **실시간 데이터**: 어디에 올리든 Firebase(익명 로그인 + Firestore, 무료 요금제)를 씁니다. Vercel에는 실시간 데이터베이스가 없어서, Vercel에 올릴 때도 데이터는 Firebase가 맡습니다.
- **보안**: 직업과 밤 행동은 Firestore 보안 규칙으로 본인과 사회자만 볼 수 있게 막혀 있습니다.
- **룰북**: 사이트 주소 뒤에 `/rules`를 붙이면 폰에서 보기 좋은 룰북이 열립니다(예: `https://my-mafia.vercel.app/rules`). 게임 첫 화면의 「룰북 보기」로도 열립니다.

---

## 1. 파일 구성

```
mafia-web/
├─ public/              ← 사이트로 올라가는 폴더
│  ├─ index.html        ← 게임 앱
│  ├─ rules.html        ← 폰용 룰북
│  └─ config.js         ← Firebase 설정 (mafia-online-8a1f3 프로젝트로 채워져 있음)
├─ firestore.rules      ← 보안 규칙 (Firebase 콘솔에 붙여 넣기)
├─ vercel.json          ← Vercel 배포 설정
├─ firebase.json        ← Firebase Hosting 배포 설정
└─ README.md
```

## 2. 설정 없이 먼저 체험하기 (데모 모드)

사이트 주소 뒤에 `?demo`를 붙여 열면 **데모 모드**로 실행됩니다(예: `https://mafia-online.vercel.app/?demo`). 첫 화면의 「혼자 미리 체험해 보기 (데모)」로도 들어갈 수 있습니다. 그냥 열면 항상 정식 모드입니다.

1. 「데모 방 열기」 → 「테스트 참가자로 20명 채우기」 → 「직업 배정하고 첫 낮 시작」을 누릅니다.
2. 위쪽 「화면 보기」에서 사회자나 참가자를 골라 각자의 화면을 바꿔 가며 봅니다.
3. 각 단계에서 「테스트 참가자 자동 입력」을 누르면 테스트 참가자들이 대신 행동합니다.

데모 모드는 이 기기 안에서만 동작하고, 새로고침하면 처음부터 시작합니다.

## 3. Firebase 준비 (한 번만)

`config.js`에는 Firebase 프로젝트 **mafia-online-8a1f3**의 설정이 이미 들어 있습니다. 정식으로 쓰기 전에 [Firebase 콘솔](https://console.firebase.google.com/project/mafia-online-8a1f3)에서 아래 세 가지가 되어 있는지 확인하세요. 하나라도 빠지면 「연결하지 못했습니다」 또는 「권한이 없어 저장하지 못했습니다」가 뜹니다.

- [ ] **익명 로그인**: 빌드 → Authentication → 로그인 방법 → **익명**을 **사용 설정**
- [ ] **Firestore 데이터베이스**: 빌드 → Firestore Database → 데이터베이스 만들기 → 위치 **asia-northeast3 (서울)**, **프로덕션 모드**
- [ ] **보안 규칙**: Firestore Database → **규칙** 탭의 기존 내용을 지우고 이 저장소의 `firestore.rules`를 통째로 붙여 넣은 뒤 **게시**

> `config.js`의 값은 공개되어도 괜찮은 웹용 설정입니다. 데이터 보호는 보안 규칙이 맡습니다.
> 다른 Firebase 프로젝트로 바꾸려면 `public/config.js`의 값만 새 프로젝트의 `firebaseConfig`로 바꾸면 됩니다.

## 4. 사이트 올리기 (셋 중 하나)

### 방법 A. Vercel + GitHub (클릭만으로, 추천)
1. GitHub에 새 저장소를 만들고 `mafia-web` 폴더의 내용 전체(`public`, `vercel.json` 등)를 올립니다. GitHub 웹에서 파일을 끌어다 놓아도 됩니다.
2. https://vercel.com 에 GitHub 계정으로 로그인 → **Add New… → Project** → 방금 만든 저장소의 **Import**를 누릅니다.
3. 설정은 건드리지 말고 **Deploy**를 누릅니다. `vercel.json`이 `public` 폴더를 사이트로 쓰도록 이미 지정해 두었습니다.
4. 1분쯤 뒤 `https://저장소이름.vercel.app` 주소가 생깁니다.
5. Firebase 콘솔 **Authentication → 설정 → 승인된 도메인 → 도메인 추가**에 그 주소(예: `my-mafia.vercel.app`)를 넣습니다.

이후 GitHub에 파일을 고쳐 올리면 Vercel이 자동으로 다시 배포합니다.

### 방법 B. Vercel CLI (Node.js가 설치된 PC)
```bash
cd mafia-web
npx vercel            # 처음: 로그인하고 질문에 Enter로 답하면 미리보기 주소가 생김
npx vercel --prod     # 실제 주소로 배포
```
배포 후 방법 A의 5번처럼 승인된 도메인에 주소를 추가합니다.

### 방법 C. Firebase Hosting (Node.js가 설치된 PC)
```bash
npm install -g firebase-tools
firebase login
cd mafia-web
firebase use --add        # 3단계에서 만든 프로젝트 선택
firebase deploy           # 사이트 + 보안 규칙을 함께 올림
```
`https://프로젝트ID.web.app` 주소가 생깁니다. 이 주소는 승인된 도메인에 이미 들어 있어서 따로 추가할 필요가 없습니다.

> 어떤 방법이든 `config.js`를 고친 뒤에는 다시 올려야 반영됩니다.

## 5. 당일 진행

**사회자 (노트북)**
1. 사이트를 열고 **새 방 만들기**를 누릅니다. 이 브라우저가 사회자 화면이 됩니다.
2. 화면의 **QR 코드와 4자리 방 코드**를 프로젝터에 띄웁니다. 룰북 QR이 필요하면 `주소/rules`로 따로 만들어 함께 띄우세요.
3. 「시간 설정」에서 낮·밤 시간을 정합니다. 기본은 **낮 40분, 밤 20분**이고 게임 중에도 바꿀 수 있습니다(다음 낮·밤부터 적용).
4. 다 모이면 구성을 고르고 **직업 배정하고 첫 낮 시작**을 누릅니다. 게임은 **낮부터** 시작합니다(낮 → 밤 → 낮 순서). 구성은 인원에 맞춰 자동으로 바뀝니다.
5. 프로젝터에 띄울 때는 「비밀 정보 보기」를 꺼 두세요. 기본으로 꺼져 있습니다.
6. 게임 내내 사회자 화면을 켜 두세요. 시간 자동 진행, 경찰 조사 결과, 마피아끼리의 선택 공유가 사회자 화면을 통해 처리됩니다.

**진행 흐름** (낮부터 시작)
- **밤 (기본 20분)**: 마피아는 함께 탈락시킬 사람을 고르고, 경찰은 조사, 의사는 보호를 합니다. 군인은 공격을 한 번 자동으로 버팁니다. 시간이 끝나거나 사회자가 「아침 발표」를 누르면 결과가 발표됩니다.
- **낮 (기본 40분)**: 토론하면서 탈락시킬 사람에게 투표합니다. 시간이 끝나거나 사회자가 「투표 마감하고 결과 발표」를 누르면 최다 득표자가 바로 탈락합니다. 동률이면 아무도 탈락하지 않습니다. 정치인의 표는 마감할 때 2표로 계산됩니다(실시간 집계에는 1표로 보임). 최후 변론과 찬반 투표는 없습니다.
- **시간 참고**: 기본값이면 한 바퀴가 최대 1시간이고, 20명 한 판은 6~9바퀴입니다. 반나절에 여러 판을 하려면 낮 5분·밤 2분 정도로 줄이세요.

**참가자 (폰)**
1. QR을 찍거나 사이트에서 방 코드를 넣고, 이름을 넣어 **입장하기**를 누릅니다.
2. 직업은 「내 직업 보기」를 탭해야 보입니다.
3. 폰이 꺼지거나 창을 닫아도, 같은 폰의 같은 브라우저로 다시 열면 그대로 돌아옵니다.

**인원별 표준 구성**

| 인원 | 6 | 7–9 | 10 | 11 | 12–14 | 15–18 | 19–20 |
|---|---|---|---|---|---|---|---|
| 마피아 | 1 | 2 | 2 | 3 | 3 | 4 | 5 |
| 경찰 | 1 | 1 | 1 | 1 | 1 | 1 | 1 |
| 의사 | 1 | 1 | 1 | 1 | 1 | 1 | 1 |
| 군인 | – | – | 1 | 1 | 1 | 1 | 1 |
| 정치인 | – | – | – | – | 1 | 1 | 1 |

「입문」은 마피아 1명 적게(군인·정치인 없음), 「마피아 강세」는 1명 많게 배정합니다. +/− 버튼으로 직접 조정할 수도 있습니다.

## 6. 알아 두면 좋은 점

- **무료 사용량**: Firestore 무료 한도는 하루 읽기 5만 회입니다. 20명 기준 한 판에 약 7천~1만 회를 쓰므로 하루 4~5판은 무료 안에서 충분합니다. 넘으면 그날은 저장이 멈추고 다음 날 풀립니다. Vercel과 Firebase Hosting의 무료 한도는 이 정도 사용에 넉넉합니다.
- **사회자 기기는 바꾸지 마세요**: 방을 만든 브라우저만 사회자 권한을 가집니다. 기기를 바꾸거나 브라우저 데이터를 지우면 새 방을 만들어야 합니다.
- **보안 수준**: 방 코드를 아는 사람은 누구나 들어올 수 있습니다. 행사용으로 충분한 수준이며, 직업과 밤 행동은 다른 참가자에게서 막혀 있습니다.
- **리허설**: 행사 전에 노트북 1대와 폰 2~3대로 직접 들어와 보고, 나머지 자리는 테스트 참가자로 채워 한 판을 끝까지 돌려 보세요.

## 7. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 「연결하지 못했습니다」 | Authentication에서 **익명**이 켜져 있는지, 사이트 주소가 **승인된 도메인**에 있는지, 인터넷 연결 |
| 「권한이 없어 저장하지 못했습니다」 | Firestore **규칙** 탭에 `firestore.rules`를 붙여 넣고 **게시**했는지 |
| Vercel 주소에서만 연결이 안 된다 | Authentication → 설정 → **승인된 도메인**에 Vercel 주소를 추가했는지 |
| Vercel 주소가 404 | 저장소 맨 위에 `vercel.json`과 `public` 폴더가 있는지(폴더를 한 겹 더 감싸 올리지 않았는지) |
| 방 코드가 없다고 나온다 | 대문자 4자리를 정확히 넣었는지 |
| 참가자 화면이 안 바뀐다 | 와이파이/데이터 연결을 확인하고 새로고침 |
